Windows source: windows/app.py, vision.py, engine.py
Python 3.13, install windows/requirements.txt in a virtual environment.
Test: python -m unittest discover -s windows -p test_core.py -v
Build: python -m PyInstaller --noconfirm --distpath dist --workpath tools/pyinstaller-build Bullseye-Windows.spec
Frozen OCR verification (requires the local home screenshot fixture described in README.md):
Bullseye-Windows.exe --verify-screenshots tests/synthetic-home.png tests/synthetic-board.png tests/frozen-result.json
The synthetic board is a fixture, not evidence of live game execution.

Android source: android/app/src/main
Java 17, Gradle 8.9, Android Gradle Plugin 8.7.3.
SDK platform android-35-ext15 and build-tools 35.0.0.
Set sdk.dir in android/local.properties to the local Android SDK directory.
From android/: .\gradlew.bat :app:assembleRelease :app:lintRelease
APK: android/app/build/outputs/apk/release/app-release.apk
The local test release uses the Android debug signing key. Preserve that key if updating this test installation.
Use a dedicated release key before public distribution.
No ADB device connection is part of either application.
