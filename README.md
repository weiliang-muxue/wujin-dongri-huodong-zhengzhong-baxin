# 无尽冬日助手

一个 Windows EXE、一个 Android APK，打开后选择 **打熊** 或 **正中靶心**。

## 目录

- `exe/源码/`：Windows 界面、两个活动引擎、识别素材、测试和构建配置。
- `apk/源码/`：Android 工程，两个活动共用一个无障碍服务。
- 本地成品放在 `exe/无尽冬日助手-2.0.1.exe` 和 `apk/无尽冬日助手-2.0.2.apk`。
- GitHub 只保存源码、构建文件和必要的识别素材；不提交 EXE、APK、用户截图、录屏、签名密钥或本机配置。

## 使用

首页选活动，按当前页面的按钮操作。运行后使用可拖动的悬浮条暂停、继续或停止。切换活动先停止当前任务。

打熊默认使用游戏里保存的前六个预设，顺序 1→6。0～5/6 有空位；6/6 等待；地图未显示行军栏也可尝试。只匹配变异巨熊与绿色＋，出征后留在列表继续加入，保留游戏原生自动加入。不使用固定 324 秒冷却，不要求地图数字净增加。点击出征并返回列表只表示“已提交”，不保证服务器加入成功。

正中靶心首次选择活动首页和完整靶子页截图，之后保留设置。每轮读取实际余券，低于五张时检查并切到一倍，零券确认后停止。

Windows 10/11 x64，游戏窗口保持前台。Android 11 及以上，支持 ARM64、ARMv7；用户需手动开启系统无障碍权限。Android 包沿用 `cn.local.winterbear`，可在签名相同时覆盖原打熊助手；旧独立正中靶心的私有配置不能跨应用自动读取。

## 开发与验证

分别见 [Windows 构建](exe/源码/README.md)、[Android 构建](apk/源码/README.md)、[验证记录](VERIFICATION.md)。

自动识别默认参考竖屏 1080×2400 游戏布局。Windows 可以框选游戏区域；布局不同或模板未匹配时，在更多设置中校准。Android 的其他布局可在高级设置取样。

当前验证覆盖代码、录屏回放和模拟流程；没有在用户手机上完成整场活动实测。
