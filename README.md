# 无尽冬日助手

一个 Windows EXE、一个 Android APK。Android 首页可选 **打熊、正中靶心、巨兽集结、野兽集结**；Windows 仍提供打熊和正中靶心。

## 目录

- `exe/源码/`：Windows 界面、两个活动引擎、识别素材、测试和构建配置。
- `apk/源码/`：Android 工程，四个活动共用一个无障碍服务。
- 本地成品放在 `exe/无尽冬日助手-2.0.3.exe` 和 `apk/无尽冬日助手-2.1.11.apk`。
- GitHub 只保存源码、构建文件和必要的识别素材；不提交 EXE、APK、用户截图、录屏、签名密钥或本机配置。

## 使用

首页选活动，按当前页面的按钮操作。运行后使用可拖动的悬浮条暂停、继续或结束。

Android 2.1.9 可在游戏内点浮窗的“切换”选择四种任务。巨兽、野兽的等级、队数和罐头额度直接在弹窗里填写。选择新任务后结束上一任务，复用当前已连接的无障碍服务。打熊首次使用会自动尝试连接地图，靶心使用已保存的截图设置。

2.1.9 的公共图像匹配会搜索缩放比例，再在候选位置细化尺寸。四个活动复用该逻辑，颜色、多个候选和页面关联条件继续参与确认。巨兽、野兽的点击坐标按实际截图范围校验，结束后重新建立浮窗与任务状态。

2.1.10 修正公共匹配器对小图案的尺寸限制：原本只有 12 像素的编队标记缩小后仍参与搜索，最终置信度、按钮颜色和页面条件保持不变。新增逐像素缩放回归，覆盖四种活动的素材、屏幕边缘、遮挡、真实截图的缩放偏移与靶心布局。测试范围和限制见验证记录。

2.1.11 将识别到的图像比例传递到相邻控件、数字区域和行军列表。编队旗帜、目标等级、搜索等级、罐头库存和每条集结倒计时随对应标记缩放；发起集结弹窗使用标题与按钮的相对关系区分同名文字。公共匹配器补查高度相差 1 像素的候选，保持原置信度与颜色条件。打熊补用固定熊头像识别文字不完整的条目，仍需匹配绿色＋。新增整页及 Android 原生回放测试，不能只凭单个模板通过就认定整个流程适配成功。

2.1.8 在前台窗口信息暂时缺失时等待重新识别。巨兽、野兽和靶心与打熊共用前台恢复判断，明确切换应用或锁屏时暂停。靶心的截图、点击回调增加超时恢复与请求编号校验，旧任务回调无法释放新请求。点击前检查截图时效。保存的靶心参考图可用于分辨率变化后的布局定位，配置仍须与两张参考图一致。

打熊、巨兽、野兽都支持选择第 1～6 个编队，主界面与游戏内任务菜单使用同一选择控件。巨兽、野兽的同时派出队数单独设置，活动结束后重新填写本次参数。打熊沿用原有保存方式，旧编队勾选可继续使用。

2.1.7 加强暂停恢复和任务切换。出征点击后的中断会先确认结果，编队点击未确认时重新选择。巨兽、野兽回设置查看后，相同参数显示“回游戏继续”，保留本次罐头计数和队伍记录；修改参数显示“开始新任务”。屏幕旋转重建设置页时保留已经选好的参数。

四个活动统一使用巨兽的小尺寸控制条，暂停、继续时保持尺寸，收起后成为同样大小的小浮标。打熊遇到不足 10 秒的集结会向下查找后续队伍，翻页手势会绕开浮窗，必要时先收起并重新识别。暂停后继续当前步骤，已提交的出征等待结果确认。

Android 四个活动均可点悬浮窗右上角“收起”。小浮标显示活动名和“运行中”“等待空位”“等待回城”或“已暂停”等当前状态。点浮标展开，按住拖动移动。状态文字在固定大小的浮标内更新。

浮窗会读取当前屏幕、系统栏和刘海边距；打熊与靶心在展开窗口放不下时先收起再避让。屏幕尺寸变化后，旧截图不用于点击。

打熊默认勾选游戏里保存的前六个预设，可在“使用编队”中调整。单选固定使用，多选按编号循环。0～5/6 有空位；6/6 等待；地图未显示行军栏也可尝试。只匹配变异巨熊与绿色＋，出征后留在列表继续加入，保留游戏原生自动加入。不使用固定 324 秒冷却，不要求地图数字净增加。点击出征并返回列表只表示“已提交”，不保证服务器加入成功。

正中靶心首次选择活动首页和完整靶子页截图，之后保留设置。每轮读取实际余券，低于五张时检查并切到一倍，零券确认后停止。

Android 2.1.3 修正了华为反馈的卡点：巨兽详情独立识别“等级”和橙色集结按钮，不再要求被详情卡遮挡的“搜索”字样可见；预设识别只匹配旗帜图案，编队改名不影响巨兽、野兽出征。浮窗在系统限制下无法移到预留位置时自动收起，持续布局重试有时间上限。前台判断过滤助手自己的无障碍浮窗，实际切换应用或打开其他活动窗口仍停止输入。权限页实时区分未开启、已开启但未连接、连接成功。

打熊、巨兽、野兽选好预设后直接点击出征，不再核对兵力数字。游戏提示出征失败时仍按弹窗恢复，避免卡在“核对出征兵力”。

巨兽和野兽：设置等级、本次活动同时派出的队数（1～6），回地图点击开始。按现有体力和罐头额度持续循环，没有总运行时长限制。巨兽按游戏默认时间发起集结，野兽直接攻击；预设按勾选的编号从小到大循环。例如已有 4 队采集、设置 1 队巨兽，仍可派出 1 队巨兽；采集队回城不会释放巨兽额度，本次巨兽队回城后才补队。总行军 6/6 时等待物理空位。

任务识别采集资源、集结和返程图标，结合倒计时跟踪新增行军与回城。采集队切换状态或重新计时时不能继承狩猎队名额；图标完整时，单行倒计时读不清不阻止确认回城。行军列表被遮挡或匹配不明确时仍保留额度。出征后若同时有其他队伍回城，无法确认新增队伍时会暂停待检查。目标等级先定位“等级”，单独识别其后数字，读不清时重试，明确与设置不符时暂停。

可选自动使用库存罐头：每批 4 个，剩余额度不足 4 时补齐剩余额度。例如上限 100、已用 98，只再用 2 个；库存不足本批所需数量则停止。用完额度后仍使用剩余体力，直到体力不足时停止；未开启罐头则只用现有体力。只识别绿色库存“使用”，逐个核对库存减少和体力增加。暂停继续保留额度；结束任务或退出后，下次重新设置。不会购买罐头。

Windows 10/11 x64，游戏窗口保持前台。Android 11 及以上，支持 ARM64、ARMv7；用户需手动开启系统无障碍权限。Android 包沿用 `cn.local.winterbear`，可在签名相同时覆盖原打熊助手；旧独立正中靶心的私有配置不能跨应用自动读取。

Android 2.0.6：巨熊集结倒计时少于 10 秒或读不清时跳过；进入编队后时间不足也返回。出现“没时间了”提示，只点取消、返回列表换另一队，保留未发送的预设。补充华为 Mate 40 Pro 屏幕比例适配，悬浮条按可用高度缩小；保留小米原有尺寸及手动取样。遇到“士兵超过出征上限”会点确定、退回列表、重新识别绿色＋；运行悬浮条常驻并自动避开识别区域。电脑版本次保持 2.0.3。

## 开发与验证

分别见 [Windows 构建](exe/源码/README.md)、[Android 构建](apk/源码/README.md)、[验证记录](VERIFICATION.md)。

Android 四个活动共用图像定位模块：先找页面标记和按钮，再使用当前画面里的实际坐标；等级、倒计时和预设跟随对应标记。正中靶心重新定位开始按钮与靶盘，余券和结算区域跟随页面变化。公共模块可供后续活动复用，具体操作顺序仍由各活动管理。

自动模板仍以已提供的竖屏游戏样式为参考，并通过宽度归一化、相对定位和偏移回放扩展兼容；这不等于所有机型、横屏或折叠屏布局均已验证。Windows 可以框选游戏区域；Android 布局无法匹配时仍可在高级设置取样。

当前验证覆盖代码、录屏回放和模拟流程；没有在用户手机上完成整场活动实测。

## 系统权限与 Pura X

“敏感权限受限 / 受限设置”是开启无障碍之前的系统限制，与无障碍开关分开。权限准备页提供本应用信息、系统无障碍入口以及跳转失败检查；它不会自动解除系统管控，也不表示系统已认可或放行本应用。

当前 APK 不要求通讯录、定位、文件存储或额外的后台弹窗权限，截图处理不需要联网。现有签名保持不变；重新签名不能保证消除系统拦截。

HUAWEI Pura X（VDE-AL00，用户提供 HarmonyOS 7.0）通过卓易通安装的 APK，需要确认兼容环境是否提供无障碍、截图及跨应用手势能力。仅能安装或允许“后台弹窗”不代表这些功能可用。参考[华为兼容应用管控说明](https://consumer.huawei.com/cn/support/content/zh-cn16103663/)和[Android 受限设置说明](https://support.google.com/android/answer/12623953?hl=zh-CW)。

已记录的实际截图尺寸：小米 1080×2400、Mate 40 Pro 1152×2376、OPPO 1080×2374、另一个游戏截图 1260×2800；Pura X 设置页 1320×2120、录屏 720×1156。1344×2772 等属于合成比例测试。Pura X 尚无游戏截图；宽屏浮窗几何检查不等于游戏识别或卓易通真机适配通过。
