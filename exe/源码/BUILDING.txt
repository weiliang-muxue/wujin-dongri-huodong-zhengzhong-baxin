Windows 1.0.3
Run these commands inside this source directory.
Python 3.13; install requirements.txt into a virtual environment.
Run: python app.py
Test: python -m unittest discover -s . -p test_core.py -v
Build: python -m PyInstaller --noconfirm --distpath .. --workpath .build Bullseye-Windows.spec
Output: ../正中靶心-1.0.3.exe

The executable includes the Python runtime and local OCR models.
Android source and build instructions are separate, under apk/源码/.
No ADB connection is part of the Windows application.
